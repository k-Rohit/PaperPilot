### Key Contributions of NgramRL:

1. **N-gram Cache Utilization**: NgramRL maintains a per-prompt n-gram cache built from prior rollouts of the same prompt. This cache allows the system to propose draft continuations based on previously generated outputs, effectively leveraging the temporal locality of prompts in RL rollouts.
